# LinkWise AI 🚀

LinkWise AI is a powerful deep intelligence extraction platform that turns any URL into structured, actionable insights. Using advanced AI models, it analyzes web content to provide summaries, company information, and targeted extraction results.

## ✨ Key Features

- **Deep URL Intelligence**: Extract meaningful data from websites with a single link.
- **Extraction Depth Options**: Select between 'Quick Scan' for speed and 'Deep Dive' for comprehensive footprinting.
- **AI-Powered Summaries**: Get concise, high-level overviews of complex pages.
- **Interactive AI Chatbot**: Ask questions about your extraction results directly with specialized AI.
- **Smart Result Management**: View, share, and export extracted intelligence.
- **Modern UI/UX**: Polished interface with dark mode support, glassmorphism effects, and premium card layouts.
- **Strategic Gap Analysis**: Automatically identifies critically missing business elements and growth opportunities.
- **Customizable Multi-Channel Outreach**: Platform-specific drafts for Email, LinkedIn, and Twitter with custom roles, focus points, and CTAs.
- **Rivalry Mapping**: Instant identification of top competitors and market positioning logic.

## 🛠️ Tech Stack

- **Frontend**: React 18, Vite, Tailwind CSS (v4-ready)
- **AI Engine**: Google Gemini API (via `@google/genai`)
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Typography**: Outfit (Display) & Inter (Body)

## 🚀 Getting Started

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Environment Setup**:
   Create a `.env` file and add your Gemini API Key:
   ```env
   GEMINI_API_KEY=your_api_key_here
   ```

3. **Run Development Server**:
   ```bash
   npm run dev
   ```

4. **Build for Production**:
   ```bash
   npm run build
   ```
